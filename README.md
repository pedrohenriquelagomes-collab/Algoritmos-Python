# Exercícios de Algoritmos em Python

Repositório criado para armazenar os exercícios de Algoritmos e Lógica de Programação desenvolvidos em Python.

---

## 📁 Organização das Pastas

O repositório está dividido em duas partes principais:

* [**`exercicios_1_ao_45/`**](./EXRC_01_AO_45/) — Lista completa com os 45 exercícios do Lote 1.1 (estruturas sequenciais, condicionais e laços de repetição).
* [**`exercicios_18_ao_26_modulares/`**](./EXRC_18_AO_26_MODULARES/) — Refatoração dos exercícios condicionais (18 ao 26) aplicando **procedimentos (sem retorno e sem parâmetros)**, **variáveis globais** e **função `main()`**.

---
## 💻 Resumo da Lista Geral (Exercícios 01 ao 45)

* **01 ao 17:** Estruturas Sequenciais (áreas, fórmulas matemáticas, reajustes, conversões e cálculos financeiros).
* **18 ao 29:** Estruturas Condicionais (decisões, comparações, médias e ordenações).
* **30 ao 45:** Estruturas de Repetição (fatorial, séries numéricas, tabuada, Fibonacci, números primos e contagens).
  
---

## 📌 Conteúdo dos Exercícios Modulares (18 ao 26)

Esta pasta contém a reestruturação modular dos exercícios com sub-rotinas e escopo global:

| Exercício | Descrição |
| :--- | :--- |
| **Ex 18** | Diferença do maior pelo menor valor inteiro |
| **Ex 19** | Maior de dois números reais |
| **Ex 20** | Equação do 2º Grau (cálculo de raízes reais) |
| **Ex 21** | Média bimestral de 4 notas e situação (Aprovado / Exame / Retido) |
| **Ex 22** | Exibição de dois valores inteiros em ordem crescente |
| **Ex 23** | Ordenação de 4 valores (3 em ordem crescente + 1 não ordenado) |
| **Ex 24** | Verificação de número divisível por 2 e por 3 |
| **Ex 25** | Cálculo do tempo de duração de um jogo (horas e minutos) |
| **Ex 26** | Verificação se o maior número é múltiplo do menor |
